# Security policy

ArtCraft WebOS is an experimental browser application. Do not use it to store
or process sensitive information, and do not enter credentials into pages
opened through the Browser proxy while its isolation issue remains open.

## Reporting a vulnerability

Use **Security → Advisories → Report a vulnerability** in this repository to
send a private report. Private vulnerability reporting is enabled. Do not
publish exploit details in a public issue.

The project does not currently make security-support or response-time
guarantees. Reports are reviewed as maintainer capacity allows.
